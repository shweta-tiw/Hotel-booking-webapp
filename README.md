🏨 StayShelter – Airbnb-Inspired Hotel Booking App

StayShelter is a full-stack hotel booking platform inspired by Airbnb.  
Built using the powerful MERN Stack (MongoDB, Express.js, React.js, Node.js)**, this responsive web app allows users to explore, filter, and view hotel listings with a clean, modern UI.


 🚀 Key Features

- 🌐 Full-Stack Web App using MERN Stack  
- 💻 Responsive UI for mobile and desktop  
- 🏨 Hotel Listings with images, location, description, and pricing  
- 🔍 Search & Filter functionality (by location and price)  
- 🔐 User Authentication (Login / Signup) *(optional enhancement)*  
- 🔁 RESTful APIs for listing and user data  
- 🧱 Clean, Scalable Component-Based Architecture  
- ☁️ Deployed on:
  - Vercel (Frontend)
  - Render or Heroku (Backend)

---

  🛠️ Tech Stack

 🔧 Frontend
- ⚛️ React.js  
- 🧭 React Router DOM  
- 🎨 Tailwind CSS or CSS3  

  🛠 Backend
- 🟢 Node.js  
- ⚙️ Express.js  
- 🍃 MongoDB with Mongoose  
- 🔑 JWT Authentication
